# 🏨 App Hotel

Aplicativo desenvolvido em .NET MAUI para a disciplina de Desenvolvimento Mobile.

O sistema permite simular uma reserva de hospedagem, informando datas de entrada e saída, tipo de quarto e quantidade de hóspedes.

---

## 📋 Funcionalidades

- Seleção de data de Check-in
- Seleção de data de Check-out
- Escolha do tipo de quarto
- Controle da quantidade de hóspedes
- Tela "Sobre"
- Navegação entre telas
- Interface desenvolvida com XAML

---

## 🖥️ Tecnologias Utilizadas

- .NET MAUI
- C#
- XAML
- Visual Studio 2022/2026

---

## 📱 Componentes Utilizados

### Image
Exibe a imagem do hotel na tela principal.

### DatePicker
Permite selecionar as datas de entrada e saída.

### Picker
Permite selecionar o tipo de quarto.

### Stepper
Permite escolher a quantidade de hóspedes.

### Button
Executa as ações de reserva e navegação.

### Label
Exibe textos e informações na interface.

## 📄 Descrição dos Arquivos

### MainPage.xaml

Responsável pela interface principal do aplicativo.

### MainPage.xaml.cs

Contém a lógica de funcionamento da tela principal.

### SobrePage.xaml

Tela com informações do projeto e do desenvolvedor.

### SobrePage.xaml.cs

Inicialização da tela Sobre.

### App.xaml

Arquivo de recursos globais do aplicativo.

### App.xaml.cs

Define a tela inicial da aplicação.

### MauiProgram.cs

Responsável pela configuração e inicialização do .NET MAUI.
